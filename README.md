# CYBER STORY LAB v1.1 FREE MODE

利用者本人が作者になる4コマ漫画制作Webアプリです。完成作品は、4コマ画像だけでなく **ページをめくって読むデジタル絵本** として閲覧・保存できます。

現在の本番版は **無料運用を優先し、外部AIをOFF** にしています。物語・画像をGemini等へ送信しません。お題候補、質問ヒント、作画ヒント、画像の見やすさ調整は端末内の無料ロジックで行います。

## 制作の考え方
- 作者は利用者本人
- システムは答えや完成ストーリーを作らない
- 変な展開、不思議な言葉、独特な絵を普通に直さない
- 1コマ = A4コピー用紙1枚
- 原画4枚を撮影して4コマに自動配置
- 完成した作品は「読む体験」のあるデジタル絵本へ変換

## 今できること
- お題を自分で入力 / 困った時だけ候補を5個表示
- 主役を自由に決める。人間・動物・物・正体不明でもOK
- 4コマを1問ずつ制作
- 各コマで「答え」ではなく質問ヒントを表示
- A4 4枚分の作画ヒントを自動整理
- 原画4枚を撮影 / アップロード
- 画像処理は端末内のみ
  - 原画そのまま
  - 線を見やすく
  - 白黒くっきり
- 文章入り4コマを自動レイアウト
- 2×2 / 縦4コマ
- PNG保存
- IndexedDB作品棚
- 作者ごとに5作品で「第1巻」進捗
- 第1巻をA4印刷 / PDF保存
- 全作品バックアップ / 復元
- 作者別の制作途中保存 / 再開
- 完成した1作品を6ページのデジタル絵本として読む
- 5作品を約27ページの「デジタル絵本 第1巻」として読む
- 左右ボタン / キーボード / スワイプでページ送り
- 全画面表示
- **画像と文章を埋め込んだ単体HTMLファイルとして保存**し、別PCでもオフライン閲覧

## 保存について
制作途中の文章と原画、完成作品は基本的にその端末のブラウザ内へ保存します。端末変更・ブラウザデータ削除に備え、スタッフは作品棚の **「全作品を保存」** から定期的にバックアップファイルを保存してください。

完成後に3Fや別端末へ渡す場合は、作品棚から **「デジタル絵本で読む」→「絵本ファイル保存」** を使います。生成される `.html` ファイルはブラウザだけでページをめくって読めます。

複数利用者で同じPCを使う場合は、作者名を入力して **「途中保存」** を押すと、その作者専用の制作途中データが残ります。次回は **「制作途中」** から再開できます。

## 料金安全設計
本番設定 `AI_MODE` は `free` です。

この状態では、仮に `GEMINI_API_KEY` が環境に存在しても `/api/story-help` と `/api/image-finish` は外部AIを呼び出さず、FREE_MODEとして停止します。

```json
"AI_MODE": "free"
```

外部AIを将来使う場合だけ、サイ校側の契約・請求先を準備した後に `AI_MODE=gemini` とSecretを設定します。個人アカウントのAPIキーを本番運用へ入れない方針です。

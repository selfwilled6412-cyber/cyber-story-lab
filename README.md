# CYBER STORY LAB v1.2 FREE MODE

利用者本人が作者になる4コマ漫画／デジタル絵本制作Webアプリです。

v1.2では、絵が苦手でも参加できるように **「ラフ＝設計図」方式** へ変更しました。利用者は丸・線・矢印・文字メモなどの簡単なラフを描き、運用側の画像AIを接続した場合だけ、そのラフを参考に **AIが一から絵本イラストとして再作画** します。ラフを清書・補正する方式ではありません。

現在の本番設定は引き続き **`AI_MODE=free`** です。外部AIへの通信も画像生成課金も発生しません。

## 制作の考え方
- 作者は利用者本人
- お題、主役、4コマの出来事は利用者が決める
- システムは答えや完成ストーリーを勝手に作らない
- 変な展開、不思議な言葉、独特な形を普通に直さない
- 絵は完成画を描かなくてよい。丸・棒人間・矢印・メモでラフを作る
- AI再作画時も、ラフの構図・位置関係・奇妙な特徴を優先する
- 完成作品はページをめくるデジタル絵本へ変換できる

## v1.2の新しい制作フロー
1. お題を決める
2. 主役を決める
3. 4コマを1コマずつ考える
4. 文章を確認する
5. **主人公の特徴を決め、A4に4枚のラフを描く**
6. **ラフを撮影して取り込み、AI接続時は一から再作画する**
7. 完成作品を作品棚へ保存する
8. デジタル絵本として読む／HTML絵本として保存する

## ラフ→AI再作画
### 主人公固定（CHARACTER LOCK）
- 主人公の特徴を短い文章で保存
- 主人公ラフは任意
- AI接続時は「主人公見本」を1枚生成
- 4コマ再作画時に同じ主人公見本を参照し、顔・色・服・固有特徴をそろえる

### 各コマ
- 左側：利用者本人のラフ
- 右側：AIが一から描き直した絵本イラスト
- 完成後もラフと比較できる
- 「帽子を黄色に戻して」「月を左へ」など、利用者が短い修正指示を入れて再生成できる
- AIが未接続でも「ラフのまま完成へ使う」で制作を止めない

### 画風
- やさしい絵本
- 水彩
- ポップ
- クレヨン・色鉛筆風

## AI再作画の安全設計
AI再作画APIは `/api/reillustrate` です。

本番で外部AIが起動するには、次の **3条件すべて** が必要です。
- `AI_MODE=gemini`
- Cloudflare Secret `GEMINI_API_KEY`
- Cloudflare Secret `AI_ACCESS_PIN`

APIキーだけを登録してもAIは起動しません。スタッフPINがない状態では外部AI呼び出しをブロックします。

現在は以下のため、AI課金は発生しません。

```json
"AI_MODE": "free"
```

将来AIを有効化するときは、個人アカウントではなく運用側の契約・請求先を用意してからSecretを設定します。

画像モデルは `gemini-3.1-flash-image` を接続できる状態にしています。モデル名は環境変数 `GEMINI_IMAGE_MODEL` で差し替え可能です。

## 既存機能
- 無料のお題候補／質問ヒント
- 4コマ文章制作
- 自動保存
- 利用者別の制作途中保存・再開
- A4ラフ4枚の撮影／アップロード
- 完全無料時は原画そのままでも完成可能
- 作品棚
- 作者別フィルタ
- 全作品バックアップ／復元
- 4コマPNG保存
- 作者ごとに5作品で第1巻
- 第1巻をA4印刷／PDF保存
- 1作品を6ページのデジタル絵本として読む
- 5作品を約27ページのデジタル絵本 第1巻として読む
- 左右ボタン／キーボード／スワイプ／全画面
- 画像と文章を埋め込んだ単体HTML絵本を保存し、別PCでオフライン閲覧

## 保存について
制作途中の文章とラフ、完成作品は基本的にその端末のブラウザ内へ保存します。端末変更・ブラウザデータ削除に備え、スタッフは作品棚の **「全作品を保存」** から定期的にバックアップしてください。

主人公ラフ／主人公見本は作者名ごとに専用IndexedDBへ保存します。
